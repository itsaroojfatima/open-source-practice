# 🤝 Contributing to Open Source Practice

Thank you for your interest in contributing to **Open Source Practice**! 🎉  
We welcome contributions from everyone, especially beginners who are taking their first steps in the open-source world.

---

## 🌟 Code of Conduct

To ensure a welcoming, inclusive, and safe environment:
- Be respectful, empathetic, and constructive in discussions and code reviews.
- Encourage beginners and help each other learn.
- No harassment, hate speech, or derogatory comments will be tolerated.

---

## 🚀 How to Contribute

Here are a few ways you can contribute to this project:
1. **Improve Documentation**: Fix typos, clarify instructions, or add translations.
2. **Add Helpful Resources**: Suggest useful beginner tools, tutorials, or Git cheatsheets.
3. **Practice GitHub Flow**: Fork, create a branch, submit a test Pull Request, and practice handling review feedback.
4. **Report Issues**: Found something broken or confusing? Open an [Issue](https://github.com/itsaroojfatima/open-source-practice/issues).

---

## 🛠️ Step-by-Step Git Workflow

### 1. Fork the Repository
Click the **Fork** button at the top right of this repository to create your own copy.

### 2. Clone Your Fork
```bash
git clone https://github.com/<YOUR-USERNAME>/open-source-practice.git
cd open-source-practice
```

### 3. Create a Feature Branch
Use a descriptive branch name:
```bash
git checkout -b feat/your-feature-name
# or
git checkout -b fix/issue-description
```

### 4. Make Your Changes
Make clean, focused changes. Avoid making unrelated changes in a single branch.

### 5. Commit Guidelines
Write clear and meaningful commit messages following standard conventions:
- `feat:` for new features or additions
- `fix:` for bug fixes
- `docs:` for documentation updates
- `style:` for formatting or styling without code changes
- `refactor:` for code restructuring

Example:
```bash
git add .
git commit -m "docs: add git cheatsheet reference"
```

### 6. Push to Your Fork
```bash
git push origin feat/your-feature-name
```

### 7. Open a Pull Request
- Go to the original repository.
- Click **"Compare & pull request"**.
- Provide a clear title and description explaining the purpose of your changes.
- Submit the PR and wait for a review!

---

## ✅ Pull Request Checklist

Before submitting your PR, make sure:
- [ ] Your branch is up to date with the latest `main` branch.
- [ ] Your commit messages are descriptive and follow conventions.
- [ ] You have tested your changes locally.
- [ ] You haven't accidentally overwritten other contributors' work.

Thank you for contributing and making open source welcoming for everyone! ✨
