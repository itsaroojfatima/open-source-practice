## 🎯 Purpose & Goals

The main goals of this repository are:
- 💡 **Learn Git & GitHub**: Practice standard commands like `clone`, `branch`, `commit`, and `push`.
- 🤝 **Master Pull Requests**: Understand how to fork, create branches, write clean commit messages, and open PRs.
- 💬 **Collaboration**: Experience how code reviews and team discussions work in open-source projects.
- 🛡️ **Zero Fear**: Make mistakes and learn without worrying about breaking production systems!

## 🛠️ Step-by-Step Contribution Guide

Follow these simple steps to make your contribution and open your Pull Request:

### 1. Fork the Repository
Click on the **Fork** button at the top-right corner of this repository page to create a copy in your personal GitHub account.

### 2. Clone Your Fork
Clone your forked repository to your local machine using your terminal:
```bash
git clone https://github.com/<YOUR-USERNAME>/open-source-practice.git
cd open-source-practice
```

### 3. Create a New Branch
Always create a new branch for your changes instead of working on `main`:
```bash
git checkout -b feature/add-your-name
```
*(Tip: Name your branch descriptively, e.g., `feature/add-ali`, `fix/readme-typo`)*

### 4. Make Your Changes
You can:
- Add your name and GitHub profile link to the [Contributors](#-contributors) table below.
- Fix typos or suggest improvements to the documentation.
- Add simple practice code snippets or helpful resources.

### 5. Stage & Commit Your Changes
Stage your files and write a meaningful commit message following conventional commits:
```bash
git add .
git commit -m "docs: add <your-name> to contributors list"
```

### 6. Push to Your Fork
Push your branch to your GitHub repository:
```bash
git push origin feature/add-your-name
```

### 7. Create a Pull Request (PR)
- Go to the original [itsaroojfatima/open-source-practice](https://github.com/itsaroojfatima/open-source-practice) repository.
- You will see a banner saying **"Compare & pull request"**. Click on it!
- Fill in a clear title and description explaining what you added.
- Click **"Create pull request"**! 🚀

## 📜 Community Guidelines & Best Practices

To keep this space friendly and productive for everyone:
- 🌟 Be respectful and supportive of fellow contributors.
- 🧹 Keep your pull requests focused on a single change or feature.
- 🚫 Avoid deleting or overwriting other contributors' entries.
- 📚 If you see a beginner struggling, feel free to help them in comments!
